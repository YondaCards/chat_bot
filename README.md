# Yonda — ИИ-бот продаж в Instagram Direct

MVP: бот ведёт горячих лидов из рекламы Click-to-Direct до скриншота оплаты, ведёт воронку в Google Sheets и передаёт диалог менеджерам в группу Telegram.
